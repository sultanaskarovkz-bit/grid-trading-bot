# Grid Trading Bot

Мультивалютный адаптивный сеточный торговый бот для Forex.

---

## Быстрый старт

**Mac:** двойной клик по `Запустить бота.command`

**Windows:** двойной клик по `start.bat`

Браузер откроется автоматически с панелью управления.

Нужен Python 3.11+ (скачать с https://python.org).

---

## Что делает бот

- Анализирует 6 валютных пар (EURUSD, GBPUSD, EURCHF, EURJPY, USDCHF, USDJPY)
- Сам открывает и закрывает сделки через MetaTrader 5
- Присылает сигналы и результаты в Telegram
- Тестирует стратегию на исторических данных
- Автоматически подбирает лучшие настройки

## Как работает

| Функция | Описание |
|---------|----------|
| Адаптивная сетка | Расстояние между ордерами подстраивается под волатильность |
| Таймауты | 30мин, 1ч, 2ч, 4ч между уровнями |
| Трендовый фильтр | Торгует только по направлению тренда |
| Корреляционный фильтр | Не дублирует позиции на похожих парах |
| Сессионный фильтр | Торговля только London + NY |
| Тейк-профит | Автоматическое закрытие в плюс |
| Trailing Stop | Защита прибыли при откате |
| Сканер рынка | 4 типа сигналов: EMA, пробои, откаты, импульсы |
