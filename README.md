## Быстрый старт

### 1. Установка

```bash
git clone https://github.com/YOUR_USERNAME/grid-trading-bot.git
cd grid-trading-bot
pip install -r requirements.txt
```

Или на Windows — просто запустите `start.bat`

### 2. Запуск панели управления

```bash
streamlit run dashboard.py
```

Откроется в браузере: `http://localhost:8501`

### 3. Настройка Telegram

В панели управления > **Telegram** > введите Token и Chat ID

## Режимы работы

### Онлайн-сигналы (Telegram)

```bash
python main.py signals --token "BOT_TOKEN" --chat-id "CHAT_ID"
```

Бот анализирует рынок 24/5 и присылает сигналы:

- Входы (LONG / SHORT) с ценой, ATR, причиной
- Закрытия с результатом (+$320.00 / -$150.00)
- Статус портфеля каждые 4 часа
- Обзор рынка каждые 8 часов

### Бэктест

```bash
python main.py backtest --start 2024-06-01 --end 2026-04-01
```

### Оптимизация параметров

```bash
python main.py optimize --trials 200 --metric sharpe_ratio
```

### Live-торговля (MetaTrader 5)

```bash
python main.py live --server "broker.com" --login 12345 --password "pass"
```

## Особенности алгоритма

| Компонент | Описание |
|-----------|----------|
| **Адаптивная сетка** | ATR подстраивает расстояние под волатильность |
| **Таймауты** | 30мин > 1ч > 2ч > 4ч > 8ч между уровнями |
| **Трендовый фильтр** | EMA определяет направление входа |
| **Корреляционный фильтр** | Блокирует дублирование на похожих парах |
| **Сессионный фильтр** | Торговля только London + NY |
| **Per-pair TP/SL** | Каждая пара управляется независимо |
| **Trailing Stop** | Защита прибыли при откате |
| **Адаптивный cooldown** | Увеличение паузы после серии убытков |
| **Сканер рынка** | 4 типа сигналов: EMA, пробои, откаты, импульсы |

## Предупреждение

Результаты бэктеста **не гарантируют** будущую прибыль. Торговля на финансовых рынках сопряжена с риском потери капитала. Всегда начинайте с демо-счёта.
