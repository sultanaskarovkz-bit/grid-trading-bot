БЫСТРЫЙ СТАРТ
--------------

  Mac/Linux:
    Откройте Terminal, перетащите start.sh в окно, нажмите Enter.
    Браузер откроется сам.

  Windows:
    Двойной клик по start.bat.
    Браузер откроется сам.

  Единственное условие - установленный Python 3.11+
    Mac:     brew install python3
    Windows: https://python.org (галочка "Add to PATH")


ЧТО ДАЛЬШЕ
-----------

  1. Подключите биржу (выберите брокера из списка)
  2. Нажмите "Открыть сделки" - бот проанализирует рынок
  3. Подключите Telegram для уведомлений

  Подробнее - в файле ИНСТРУКЦИЯ.txt
