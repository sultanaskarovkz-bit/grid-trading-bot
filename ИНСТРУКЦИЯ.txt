1. ЧТО ВАМ НУЖНО ПЕРЕД НАЧАЛОМ
================================================================

  - Компьютер с Windows 10/11
  - Python 3.11 или новее (скачать: https://python.org)
    ВАЖНО: при установке Python поставьте галочку
    "Add Python to PATH" на первом экране!

  - Telegram (для получения сигналов)
  - MetaTrader 5 (только для автоторговли, необязательно)

2. УСТАНОВКА (1 минута)
================================================================

  Способ 1 (простой):
    Дважды кликните на файл start.bat
    Он сам установит всё что нужно

  Способ 2 (ручной):
    Откройте командную строку (Win+R, cmd, Enter)
    Перейдите в папку бота:
      cd путь\к\trading_bot
    Установите зависимости:
      pip install -r requirements.txt

3. ЗАПУСК ПАНЕЛИ УПРАВЛЕНИЯ
================================================================

  Дважды кликните start.bat

  Откроется браузер с панелью управления.
  Адрес: http://localhost:8501

  В панели управления вы можете:
  - Настроить параметры сетки (без кода!)
  - Подключить Telegram
  - Запустить бэктест
  - Запустить оптимизацию
  - Запустить онлайн-сигналы
  - Посмотреть инструкцию по MT5


================================================================
4. НАСТРОЙКА TELEGRAM
================================================================

  Шаг 1. Откройте Telegram, найдите @BotFather
  Шаг 2. Отправьте /newbot
  Шаг 3. Придумайте имя боту (например: MyTradingSignals)
  Шаг 4. Придумайте username (например: my_trading_signals_bot)
  Шаг 5. Скопируйте TOKEN — длинная строка типа:
         123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11

  Шаг 6. Найдите @userinfobot в Telegram
  Шаг 7. Нажмите Start — бот покажет ваш Chat ID (число)

  Шаг 8. В панели управления перейдите в раздел "Telegram"
  Шаг 9. Вставьте Token и Chat ID
  Шаг 10. Нажмите "Проверить подключение"

  Если всё правильно — в Telegram придёт сообщение!


================================================================
5. ЗАПУСК ОНЛАЙН-СИГНАЛОВ
================================================================

  В панели управления:
    1. Перейдите в "Онлайн-сигналы"
    2. Нажмите "Запустить бота"

  Бот начнёт:
    - Проверять рынок каждые 5 минут
    - Присылать сигналы в Telegram (LONG/SHORT)
    - Присылать статус портфеля каждые 4 часа
    - Присылать обзор рынка каждые 8 часов

  Бот работает 24/5 (пн-пт). На выходных спит.

  Для остановки: нажмите "Остановить бота" в панели


================================================================
6. ПОДКЛЮЧЕНИЕ К METATRADER 5
================================================================

  Для автоматической торговли (не только сигналы):

  Шаг 1. Установите MetaTrader 5 с сайта брокера
  Шаг 2. Войдите в свой торговый счёт
  Шаг 3. В MT5: Сервис -> Настройки -> Советники
         Включите "Разрешить алгоритмическую торговлю"
  Шаг 4. Установите пакет: pip install MetaTrader5
  Шаг 5. В панели управления перейдите в "MetaTrader 5"
  Шаг 6. Введите данные сервера, логин и пароль
  Шаг 7. Скопируйте команду запуска

  ВАЖНО: Начинайте с ДЕМО-СЧЁТА!

7. КАК МЕНЯТЬ НАСТРОЙКИ СЕТКИ
================================================================

  В панели управления -> "Настройки сетки"

  Все параметры с описаниями. Основные:

  Базовое расстояние  — пипсы до 2-го ордера.
                        Больше = реже усредняет, безопаснее.
                        Рекомендация: 30-50 пипсов.

  Множитель лота      — как растёт объём по уровням.
                        1.5 = умеренно, 2.0 = агрессивно.

  Тейк-профит         — при каком % прибыли закрыть.
                        1-2% = часто фиксирует.
                        3-5% = реже, но больше.

  Стоп-лосс           — при каком % убытка закрыть.
                        Рекомендация: 7-15%.

  После изменений нажмите "Сохранить" и перезапустите бота.

  Для автоподбора лучших настроек используйте "Оптимизацию" —
  алгоритм сам найдёт лучшие параметры за несколько минут.

8. ЧТО ПРИСЫЛАЕТ БОТ В TELEGRAM
================================================================

  Все сообщения на русском языке.

  СИГНАЛ НА ВХОД:
    Зелёный кружок — LONG (покупка)
    Красный кружок — SHORT (продажа)
    Показывает: пару, цену, ATR, тренд, причину входа

  ЗАКРЫТИЕ СДЕЛКИ:
    Галочка — закрыто в ПЛЮС (+$xxx.xx)
    Крестик — закрыто в МИНУС (-$xxx.xx)
    Показывает: причину, длительность, количество уровней

  СТАТУС ПОРТФЕЛЯ (каждые 4 часа):
    Баланс, плавающий P&L, P&L за день, просадка

  ОБЗОР РЫНКА (каждые 8 часов):
    Тренды и сигналы по всем 6 парам

9. FAQ
================================================================

  В: Бот торгует сам?
  О: В режиме "Онлайн-сигналы" — нет, только шлёт
     рекомендации. Вы сами решаете входить или нет.
     В режиме "Live" через MT5 — да, торгует автоматически.

  В: Работает ли бот по реальным данным?
  О: Да. Данные загружаются с Yahoo Finance в реальном
     времени. В режиме Live — напрямую из MetaTrader 5.

  В: Сколько сигналов в неделю?
  О: В среднем 7-12 сигналов в неделю. Минимум 5.

  В: Можно добавить другие пары?
  О: Да. Отредактируйте DEFAULT_PAIRS в config.py
     или обратитесь к разработчику.

  В: Нужен ли VPS?
  О: Для постоянной работы 24/5 — да, нужен VPS
     или компьютер который не выключается.
     Для периодического анализа — нет.

  В: Гарантирована ли прибыль?
  О: Нет. Торговля на финансовых рынках связана с
     риском потери капитала. Бэктест показывает
     исторические результаты, не будущие.
     Всегда начинайте с демо-счёта.
