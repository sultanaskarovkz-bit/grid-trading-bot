КАК ЗАПУСТИТЬ (Mac)
================================================================

  Шаг 1. Установите Python (один раз)
    - Зайдите на https://python.org
    - Нажмите жёлтую кнопку "Download Python"
    - Откройте скачанный файл и установите как обычное приложение

  Шаг 2. Распакуйте ZIP-архив с ботом
    - Дважды кликните по скачанному архиву
    - Появится папка с файлами бота

  Шаг 3. Запустите бота
    - Найдите файл "Запустить бота.command" в папке
    - Кликните по нему ПРАВОЙ кнопкой мыши
    - Выберите "Открыть"
    - В появившемся окне нажмите "Открыть"
    - Это нужно сделать только один раз, дальше
      можно запускать обычным двойным кликом

  Через 10-15 секунд браузер откроется автоматически
  с панелью управления. Готово.

  Если браузер не открылся - зайдите на http://localhost:8501


КАК ЗАПУСТИТЬ (Windows)
================================================================

  Шаг 1. Установите Python (один раз)
    - Зайдите на https://python.org
    - Нажмите "Download Python"
    - При установке ОБЯЗАТЕЛЬНО поставьте галочку
      "Add Python to PATH" на первом экране!

  Шаг 2. Распакуйте ZIP-архив с ботом

  Шаг 3. Дважды кликните по файлу "start.bat"

  Браузер откроется автоматически. Готово.


================================================================
КАК ПОЛЬЗОВАТЬСЯ
================================================================

  После запуска открывается панель управления в браузере.
  Слева меню, справа - содержимое раздела.

  1. ПОДКЛЮЧЕНИЕ К БИРЖЕ
     - Выберите брокера из списка (Exness, RoboForex и др.)
     - Выберите сервер из списка
     - Введите логин и пароль от торгового счёта
     - Нажмите "Подключиться"
     - Для автоторговли нужен MetaTrader 5 (только Windows)

  2. ТОРГОВЛЯ
     - Кнопка "Проанализировать рынок и открыть сделки" -
       бот проанализирует 6 валютных пар и сам откроет позиции
     - Кнопка "Обновить" - показывает текущие открытые сделки
     - Кнопка "Закрыть всё" - закрывает все сделки
     - "Автоматический режим" - бот торгует сам пока включён

  3. TELEGRAM (уведомления на телефон)
     - Откройте @BotFather в Telegram, отправьте /newbot
     - Придумайте имя и username
     - Скопируйте TOKEN
     - Откройте @userinfobot, скопируйте Chat ID
     - Вставьте в панели, нажмите "Отправить тестовое"

  4. БЭКТЕСТ (тест на истории)
     - Выберите даты и размер депозита
     - Нажмите "Запустить тест"
     - Увидите график роста, список сделок и статистику

  5. ОПТИМИЗАЦИЯ
     - Нажмите "Запустить" - бот сам подберет лучшие настройки
     - Занимает 5-15 минут, результат сохраняется автоматически

  6. НАСТРОЙКИ СЕТКИ
     - Все параметры с пояснениями прямо в панели
     - После изменений нажмите "Сохранить"


================================================================
ЧТО ЗНАЧАТ НАСТРОЙКИ СЕТКИ
================================================================

  Расстояние между ордерами
    Через сколько пунктов бот открывает следующий ордер
    если цена идёт против. Больше = безопаснее.

  Множитель объёма
    Во сколько раз растёт объём каждого следующего ордера.
    1.0 = одинаковый. 1.5 = умеренно. 2.0+ = агрессивно.

  Максимум уровней
    Сколько ордеров максимум в одной корзине.

  Тейк-профит (%)
    При какой прибыли закрыть корзину. 1-2% = часто и понемногу.

  Стоп новых ордеров (%)
    При какой просадке перестать добавлять ордера.

  Аварийный стоп (%)
    При какой просадке закрыть всё с убытком. Последняя защита.

  Трендовый фильтр
    Торгует только по направлению тренда.

  Корреляционный фильтр
    Не дублирует позиции на похожих парах.

  Сессионный фильтр
    Торгует только когда биржи работают (Лондон + Нью-Йорк).

================================================================
ЧАСТЫЕ ВОПРОСЫ
================================================================

  Работает на Mac?
    Сигналы в Telegram - да. Автоторговля через MT5 -
    только на Windows (или через виртуалку/VPS).

  Бот торгует сам?
    В режиме "Торговля" через MT5 - да, полностью сам.
    В режиме "Telegram-сигналы" - нет, только рекомендации.

  Данные настоящие?
    Да. Цены берутся с биржи в реальном времени.

  Нужен ли VPS?
    Если нужна работа когда компьютер выключен - да.
    Для разового анализа и тестов - нет.

  Сколько сигналов в неделю?
    7-12 сигналов в среднем.
